**Two supporting claims retracted before merge** (both raised in review, re-measured on

   `weak` only suppresses the "unknown configuration option" error for a name that no import
   registers. `warningAsError` is a core `register_builtin_option` (`Lean/Log.lean:56`), so
   the prefix would be unnecessary here, not harmful. The lakefile comment states this.

   `Style.longLine.longLineLinter` skips `import` lines — all 125 are `import` lines and none
   contains `http`. The conclusion survives and is now measured directly: of the 25 files
   carrying the in-file disable, **24** contain a line over 100 codepoints that survives both
   exclusions (149 such lines), and `linter.style.longLine` is a member of
