- **F-1 nested braces — open, and LIVE on the lane. The recorded "0 in the lane" is wrong and is

  `safe-to-delete`, and they hit exactly **one lane module**:

  three** of its declarations (`log_partitionFunctionAlongExhaustion_latticeGraph_cubicExhaustion_{neg_h,eq_abs_h,monotone_abs_h}`),

  (`exact docs/index.md:1381`), so the module is fully dead *only* because of this fail-open.
- **F-2/F-3 — FIXED by PR #4759 (main `ecdaf2e5`).** The real mechanism was `_apply_doc_channel`:
  a glob resolving to **two or more** declarations and not starting with `_`/`.` was classified as

  `MAX_CHARGED_GLOB_MATCHES = 10` declarations to each of its matches. The two documented
  ALL-IN-LANE sites (`docs/index.md:1427` `freeEnergyAlongExhaustion_latticeGraph_ge_log_two*`,

  `safe-to-delete` count fell 1091 → 976. Globs above the threshold remain a *known, printed*
  residue (report section "documentation family labels"), by design.
- **New residual — zero-resolution wildcard, open.** Recorded from the independent review of
  #4759 (https://github.com/phasetr/ising-model/issues/4746#issuecomment-5105348942); it is not a
  regression of #4759 (identical pre-#4759, and #4759 strictly shrinks the fail-open set).
  `_resolve_fragment` anchors the regex against the whole token but matches only the final path
  component, so a namespace-qualified glob resolves to **zero** declarations, charges nobody, and
  is not even filed as a family label (`len(matched) >= 2` is false) — invisible in the report: no

  (`IsingModel/Concrete/LatticeGraphCorrelation/PerStageSubgraphConvergent.lean:33`, lane), cited
  at `tex/proof-guide.tex:3861`
  `` \texttt{IsingModel.\{magnetization,truncated2,susceptibility,magnetization\_total\}\_convergent\_*} ``.
  Counterfactual, measured: dropping the `IsingModel.` prefix at that site moves the declaration
  `safe-to-delete → uncertain` (shorthand, 8 named), so the module leaves the fully-dead set.
  Candidate fixes (not authorised here): match against `name.rsplit(".", 1)[-1]`; file a family
  label / coverage warning on zero-resolution wildcards; or, minimally, restate `L12` and the

- **F-5 — `A/B` inline alternation, open (found 2026-07-28, batch 8, PR #4771).** `_nameish`
  rejects any token containing `/`, so a slash-alternated citation such as
  `` `truncated3/4Infinite_latticeGraph_{beta_zero,J_zero_of_pairwise_distinct}` `` at
  `docs/index.md:1368` is dropped whole at tokenisation and charges nobody. The dropped alternation
  cites `truncated3Infinite_latticeGraph_J_zero_of_pairwise_distinct`

  `safe-to-delete` although it is a `Done`-row citation. `TwoPointTruncatedHigherJZero.lean` is
  added to the fail-closed exclusion list (may not be deleted by any batch) until F-5 is repaired
  or the citation is rewritten without `/`.
- **F-6 — glob-spelled elision head, open (found 2026-07-28, batch 8 review, PR #4771).**
  `elided_prefix_matches` only licenses a bare-suffix elision (e.g. `_monotone_{J,h,beta}`) from a
  head spelled *verbatim* on the same line, because `_cited_declaration_names` collects verbatim /
  brace-expanded declaration names only — a head spelled as a glob or `...`-elision (e.g.
  `` `freeEnergyInfinite_..._bounds` ``) establishes no admissible prefix, so every bare suffix that
  follows it on the line silently skips the family it names. **Double invisibility**: if the same
  line already charges some other family via a different token, `charged` is non-empty and the line
  is never filed in the "documentation family labels" residue list either, so the miss shows up in
  neither the verdict nor the human-facing residue list. Live example: `docs/index.md:1362` (and
  the `_monotone_h` occurrence at `docs/index.md:364`) cites
  `freeEnergyInfinite_latticeGraph_cubicExhaustion_monotone_{J,h,beta}` via the glob-spelled head
  `` `freeEnergyInfinite_..._bounds` `` — measured: `_monotone_J` 48 matched / 11 charged (the
  `freeEnergyInfinite_...` declaration NOT charged), `_monotone_h` 42/9, `_monotone_beta` 48/12.
  A fail-closed elided-prefix sweep built to catch this (resolve every head — verbatim/`{}`/`A/B`/
  glob/`...`-elided alike — against the base declaration set, take every `_`-prefix of every
  resolved name as admissible, charge every bare-suffix token on the line) confirms **4 citations**
  it should have blocked. `IsingModel/Concrete/LatticeGraphCorrelation/TwoPointFreeEnergyInfMonotoneCubicEx.lean`
  is added to the fail-closed exclusion list until F-6 is repaired or the citing rows
  (`docs/index.md:1362`, `:364`) are rewritten to name the surviving generic-Λ results.
