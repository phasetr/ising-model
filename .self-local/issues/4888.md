## Summary

Extend the existing `correlationAlongExhaustion` family equations only to cohesive consumer
families that demonstrably repeat the same proof skeleton. Census: 81 `by_cases ... subset
Λ.volume` sites in 40 modules (audit population, not an automatic replacement count). Work:
classify the 81 sites, select one family with >=3 genuinely matching consumers, run a one-family
pilot using `correlationAlongExhaustion_family_eq_of_subset` /
`correlationAlongExhaustion_family_eq_zero_of_not_subset`, compare proof size/import closure
before any second family. Constraints: no higher-order predicate-eliminator form, no mechanical
rewrite of all 81 sites, no hiding mathematically distinct subset conditions.
