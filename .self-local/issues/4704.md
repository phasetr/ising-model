## Summary
Repo-wide stale `.lean` file/declaration references in shipped documentation, discovered as a
side finding during the #4700/#4701/#4703 governance re-verification. Pre-existing debt from
earlier module reorganizations; not caused by, and not covered by, PR #4703 or any then-open
issue (#4700, #4692, #4642, #4563, #4559 all checked disjoint).

## Evidence
- `docs/index.md`: **9** distinct references to `.lean` files/declarations that do not exist
  anywhere in the current tree (basename-nonexistent; originally counted as 12, see UPDATE above).
- `tex/proof-guide.tex`: **156** distinct such references (rising to roughly 255 if path-level
  mismatches from module splits are also counted; originally counted as 159, see UPDATE above).
- Candidate clusters: `RangeAscoliPatches/*`, `SubseqCompactOpen/*`,
  `BranchAscoliCompactOpen/*Patches/*`, `Peierls/SingleOrbit*`, `Branches/*`. Example:
  `tex/proof-guide.tex:2603` cites `Peierls/SingleOrbitBase.lean`, which does not exist.
- 3 of the raw hits were the #4702 Mayer-order-3 file references, tracked separately under #4700
  and resolved by PR #4705 (retracted) — excluded from the counts above and from this issue's
  remaining scope.

## Scope
1. Precise per-declaration audit (file existence via `git ls-tree`, declaration existence via
   `grep -rn`) — the raw regex scan has a high false-positive rate and must not be used for blind
   deletion.
2. Retract or update each genuine stale reference.
3. Tracking only — implementation authorization/sequencing is a separate main-agent/user decision.

## Recurrence-prevention proposal (for consideration)
(a) Mandatory closing check on deletion-type PRs: `grep <deleted-decl-name> docs tex` = 0.
(b) `dev-review` audit_gate V1–V4 does not verify docs/tex-to-declaration correspondence
(the #4702 defect class: code deleted, docs left claiming Done); consider a V5 gate.
