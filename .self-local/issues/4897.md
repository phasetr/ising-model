# Issue #4897: [P2 hygiene] Survey anonymous-instance-fragility recurrence (LatticeBoundaryBED:95,107) across 28 more Peierls/Conditioning modules

**Status:** CLOSED (not planned — superseded by #4906)

**Created:** 2026-08-04
**Closed:** 2026-08-04

GitHub: https://github.com/phasetr/ising-model/issues/4897

## Summary

`dev-audit-tier1`, auditing merged PR #4894 (commit `4d62b8c47f7031874c9778d336a1ec0b72122f2c`),
found that the "anonymous-instance-fragility" pattern PR #4894 hit and remediated for 3 modules
recurs in **28 further modules** across `Peierls/` and `Conditioning/`. Modules using
`Ambient.inducedGraph (latticeGraph d) Λ` implicitly depend on two anonymous
`DecidableRel`/`Fintype` instances declared at
`IsingModel/Concrete/LatticeGraphBED/LatticeBoundaryBED.lean:95,107`, reachable only via a
fragile transitive import chain rather than a direct import — invisible to name-based scans
since both instances are anonymous.

## Not actioned this session

Filed as a follow-up per PR #4894's implementer + `dev-review` (needs dedicated follow-up, not
scope creep in PR #4894); no remediation started. Does **not** pre-authorize deleting/repointing
any of the 28 modules' imports.

## Next step

Requires a proper module-by-module survey of the 28 modules (which reach the two instances
transitively, through which chain) before any change, then remediation with the same
fail-closed build-verification discipline PR #4894 used (`lake build` 0-warning green +
`pp.all` term-identity check). Should be picked up by a future `dev-audit-tier2` pass.

## Closing rationale (2026-08-04, superseded)

Independent `dev-design` analysis (`.self-local/reports/design-4897-remediation-scope.md`, main
`3fe81b47`) found the 28-module Peierls/Conditioning scope this issue proposed is too narrow:
the true population of `inducedGraph (latticeGraph d) Λ` call sites lacking a direct import of
`LatticeBoundaryBED` is **330 repo-wide** (loose measure; 33 strict), concentrated mostly in
`Concrete/` (273+), not Peierls/Conditioning. Adding the proposed 28 imports would not
meaningfully reduce risk (330 − 28 = 302 remain) and runs against this session's import-hygiene
direction (fewer edges, not more). Closed not planned; the real structural fix (relocate the two
anonymous instances to their definition site `AmbientLattice/Defs/Core.lean:38`, eliminating the
fragility for all 330 sites with zero new import edges) is filed as its own dedicated issue:
#4906 (not pre-authorized for implementation).
