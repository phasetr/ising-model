# Issue #4718: process: artifacts committed straight to main bypassed the audit gate and left main red for two commits

**Status**: OPEN

**Created**: 2026-07-25 (`dev-issue-manager` finding during #4715/#4716 close-out, filed by
`dev-pr-clerk` per explicit instruction — a new issue was judged necessary since #4709 covers a
different defect class)

GitHub: https://github.com/phasetr/ising-model/issues/4718

## Incident

While preserving `dev-perf`'s A/B artifacts for issue #4715 (build-speed `isDefEq` cluster fix),
9 files were added under `.self-local/reports/perf-isdefeq-cluster-artifacts/` as **tracked
`.lean` files** and **committed directly to `main`** (`b4bec721`), per explicit orchestrator
instruction, rather than riding a PR.

This tripped `scripts/test_audit_gate.py:851`
(`CheckedFilesTest.test_no_tracked_lean_file_lives_outside_the_checked_roots`; tracked `*.lean`
must live only under `IsingModel` / `IsingModel.lean` / `test` / `scripts/audit`). **`main` was
red for two commits**: `b4bec721` (failure) and `b67b62fe` (follow-up attempt, also failed).
Green restored by `7991a01d` (renamed the 9 files `.lean` → `.lean.txt`).

## Root cause (a) — direct-to-main commit bypassed the CI gate

The artifacts should have ridden the same PR as the work they document, so CI would gate them
before merge. An orchestrator instruction does not authorize bypassing a process gate; this is
recorded as a `dev-pr-workflow` process deviation (branch → PR → squash-merge is the only path
to `main`, with no exceptions).

## Root cause (b) — asymmetric gate invariants for `.self-local/`

`scripts/audit_gate.py:140` (`V4_UNSCANNED_PREFIXES = (".self-local/",)`) exempts
`.self-local/` from the V4 scan, but the V1/V2 coverage self-test
(`scripts/test_audit_gate.py:851`) has **no** corresponding exemption. The `.lean.txt` rename is
a workaround for the 9 specific files, not a fix to this asymmetry. Proposed fix (config
change, requires user approval, **not implemented here**): add a matching `.self-local/`
exemption to the V1/V2 self-test, or otherwise reconcile the two invariants.

## Relation to #4709

Different defect class: #4709 is about a PR body failing to match its own diff; this issue is
about (a) a direct-to-`main` commit bypassing the PR/CI pipeline, and (b) an asymmetry in the
audit gate's own invariants.

## Suggested next step

(a) is a process-discipline reinforcement (no code change). (b) requires explicit user approval
before editing `scripts/test_audit_gate.py`'s invariants.
